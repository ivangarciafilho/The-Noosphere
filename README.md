# The-Noosphere
A Homebrew Content For Warlocks

**Live codex:** https://ivangarciafilho.github.io/The-Noosphere/

## What's here

| Page | What it is |
|---|---|
| [`index.html`](https://ivangarciafilho.github.io/The-Noosphere/) | **The Living Codex, v30.** 267 eldritch invocations and dead-magic spells for D&D 5e (2024 rules), each with a full design audit, plus Book VI, the 15-pattern design grammar. |
| [`editions/overhaul-2026-07.html`](https://ivangarciafilho.github.io/The-Noosphere/editions/overhaul-2026-07.html) | The July 2026 visual overhaul: procedural moon-circle seals, unveil wind, rolling omens, and spell level/school filters. Kept because these features have not yet been ported into the main codex. |
| [`editions/legacy-2026-06.html`](https://ivangarciafilho.github.io/The-Noosphere/editions/legacy-2026-06.html) | The first published edition (June 2026). |
| [`variants/`](variants/) | Visual-language experiments: astrolabe, sigil crest, unified HUD, compact codex, radial meters, geometric arcana, visual grammar. |

Pages keep their rules, styling, and interaction code in HTML; no build step is required. The current codex also loads `art/manifest.js` and the WebP illustrations in `art/`. Keep that directory beside `index.html` when previewing or publishing. See [`art/README.md`](art/README.md) for adding illustrations and preserving generation provenance.
